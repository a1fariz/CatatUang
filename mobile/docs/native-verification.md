# Verifikasi native dan distribusi

Jalankan integration test hanya pada emulator baru/kosong khusus tes dengan application ID `dev.catatuang.catat_uang.integration`. Marker Gradle `ORG_GRADLE_PROJECT_catatUangIntegrationTest=true` dan dart-define INTEGRATION_TEST=true menjaga pemisahan walau Flutter membuat target listener. Jangan jalankan integration test pada aplikasi reguler atau mengganti signer APK yang sudah terpasang. Skrip scripts/run-native-ci.sh menolak target non-emulator dan emulator yang sudah memiliki paket reguler; CI memakai AVD disposable API 35.

Native CI menjalankan akun lewat API Go/PostgreSQL (secure storage/Keystore, rekreasi controller, pencabutan token, login/logout tanpa kehilangan ledger), lalu SQLite/backup (reopen file, operasi inflight, transfer backup terenkripsi dua database, history pembayaran/pengaturan) dan plugin notifikasi (jadwal masih terdaftar dari adapter baru, cancel menghapus jadwal). Ini tidak membuktikan penerimaan notifikasi OS, reboot, atau pemilihan provider dokumen SAF.

Run pertama gagal sebelum tes karena partisi userdata default meminta 7,4 GB saat runner hanya tersisa 4,5 GB. Konfigurasi dibatasi data/RAM 2048M dan job membuang SDK .NET/GHC yang tidak dipakai pada runner sementara. Tidak ada AVD atau SDK workstation pengguna yang dihapus. Boot timeout 5 menit membatasi pemborosan jika emulator tidak dapat diluncurkan.

Cache Gradle dibatasi ke modules-2/files-2.1 serta wrapper; cache transforms/build yang besar tidak ikut diarsipkan. Job build juga membersihkan SDK runner yang tidak digunakan agar pembuatan arsip tidak menghabiskan disk. Perubahan ini menanggapi peringatan No space left on device saat menyimpan cache, bukan kegagalan tes aplikasi.

Emulator kemudian terbukti boot, tetapi QEMU hang saat build/instalasi NDK dan Gradle masih berjalan. Alur native kini membangun dua APK x64 terlebih dahulu, memeriksa package ID serta target Dart di kernel, lalu menghentikan Gradle sebelum emulator dimulai. Driver memakai --use-application-binary dengan timeout 8 menit per tes. Heap Gradle dibatasi 3 GiB, metaspace 1 GiB, dan dua worker. Job native berjalan paralel dengan job unit/build biasa pada VM dan database terpisah; seluruh job tetap harus lulus. Ini memisahkan kompilasi dari runtime emulator serta memperjelas tahap yang gagal.

Tes manual tersisa saat perangkat khusus tersedia: ekspor lewat dialog SAF ke Documents/provider pilihan, salin file keluar data aplikasi, salah password/file rusak, restore di instalasi kosong, izin notifikasi ditolak/diterima, pengiriman alarm saat app ditutup/reboot/battery saver, dua perangkat offline bersamaan lalu konflik/payment retry, dan pemeriksaan nilai ledger bersama pemilik data. iOS memerlukan macOS/Xcode/perangkat/signing Apple. Jangan menggunakan uninstall sebagai langkah pemulihan data.

Debug build lokal menggunakan paket reguler dan signer debug yang sudah ada. API_BASE_URL `http://10.0.2.2:8080` khusus server development; build ini bukan distribusi production. APK final di `.tools/catat-uang-final-debug.apk`, SHA-256 `7c906991b9a229afbd5658ca57301415f5a6eed18a960fc2dadd81e3705b049c`, sertifikat SHA-256 `c0480972ebad36974db01b30175f2fd6ef0af162fe12431afee759539c24578b`. Semua 32 lib Dart ditemukan cocok di debug kernel. Artefak/key/database tidak masuk Git.

Build release tidak lagi memakai debug signer secara otomatis. Siapkan keystore production di luar repo/backup finansial dan isi environment CATATUANG_KEYSTORE_PATH, CATATUANG_KEY_ALIAS, CATATUANG_STORE_PASSWORD, CATATUANG_KEY_PASSWORD melalui secret store proses/CI. Tanpa keempatnya tugas release ditolak; jangan memasukkan nilai ke gradle.properties yang dikomit. Jalankan build appbundle/apk release dengan API_BASE_URL HTTPS milik deployment yang telah diuji. Keystore/App Signing Play serta bundle identifier/domain riil dan Apple team perlu disiapkan pemilik sebelum publikasi. Tidak ada keystore production atau rilis store yang dibuat otomatis.

Pemeriksaan lokal: suite Flutter lulus, dua integrasi backend nyata lulus terpisah, analyzer bersih, debug APK berhasil, dan guard signing release teruji. Tes kalender/form zona terakhir juga lulus. Jumlah terkini dan hasil job native CI dicatat pada laporan verifikasi akhir; jangan menyamakan build APK dengan keberhasilan semua perilaku perangkat.

Pada run backup `0b2ca1f`, Android dan dua ledger lulus tetapi native gagal menemukan tombol logout setelah login. Tes akun kini mengakhiri fokus input sebelum navigasi, menunggu state controller sesi aktif/tidak sibuk maksimal 30 detik setelah submit, lalu mencari tombol yang hit-testable. Penantian state tidak mengulang request login; pumpAndSettle hanya menunggu frame, bukan selesainya network/Keystore. Perubahan ini perlu dikonfirmasi lagi melalui emulator CI, bukan dinyatakan lulus hanya dari widget test lokal.

Guard skrip sekarang mewajibkan get-state=device dan keberhasilan query daftar paket sebelum/sesudah tes. Kegagalan adb tidak dianggap daftar paket kosong. `bash scripts/test-native-guard.sh` menguji lima kondisi dengan adb mock (integration-only, paket reguler, disconnected, offline, query gagal), tanpa menyentuh perangkat/server adb nyata. Skrip ini ikut native CI sebelum build APK. Paket reguler tetap ditolak; tidak ada uninstall aplikasi pengguna.
